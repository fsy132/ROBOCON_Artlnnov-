# ROBOCON 电控教学资料

这是面向 ROBOCON 电控新队员的入门资料库，内容覆盖电控职责、软硬件基础、STM32 外设、通信、电机控制、调试、学习路径和团队协作。

## 阅读文档

完整内容请阅读：[电控教学资料（新人文档版）](./电控教学资料.md)

GitHub 会将 Markdown 文件渲染为可直接阅读的文档页面。代码工程与教学资料分开阅读，教学文档不绑定某一届比赛或某个工程路径。

## 内容导航

- 电控组职责以及与机械组、算法组的协作方式
- C 语言、STM32、通信、控制、电机和硬件基础
- Keil、CubeMX、嘉立创 EDA、仪器和 GitHub 的使用
- 先学应用后学原理、比赛导向、螺旋式深入、零存整取
- 51 单片机、C 语言、STM32、FreeRTOS 和比赛设备的学习顺序
- 分阶段实践任务、考核标准和资料库维护规范

具体芯片型号、设备协议和比赛规则，以当届官方文件及队内实际设备为准。
