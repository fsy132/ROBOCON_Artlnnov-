# R2 电控教学资料（新人版）

> 适用范围：ROBOCON 机器人电控入门、代码阅读和上手调试。
> 这份资料按“先懂概念，再看工具链，再落到代码和硬件”的顺序整理。

## 1. 电控是什么

- 电控的目标，是让机器人按预期完成运动和动作。
- 电控系统通常由三部分组成：
  - 执行机构：电机、舵机、气缸等
  - 控制器：STM32 这类单片机
  - 通信系统：CAN、UART、I2C、SPI 等
- 软件负责“怎么控”，硬件负责“能不能稳地控住”。

## 2. 最重要的几个点

- 电控不是单独写代码，而是机械、硬件、通信、控制一起工作。
- 比赛里最重要的不是花哨，而是稳定、快速、准确、可维护。
- 常见问题往往不是算法，而是：
  - 线断了
  - 协议错了
  - 参数没配对
  - 状态机卡住了

## 3. 工具链

- VS Code：写代码、看工程、调试
- CubeMX：选芯片、配时钟、配引脚、生成初始化代码
- 构建/烧录工具：完成编译和下载
- Cortex-Debug：在 VS Code 里调试
- GitHub：版本管理、资料同步、代码协作

## 4. 常见使用流程

1. 用 CubeMX 生成工程
2. 复制需要的文件到新工程
3. 用 VS Code 打开
4. 编译检查
5. 烧录到板子
6. 现场验证功能

## 5. 软件层在做什么

- 代码编写与调试
- 电机通信与控制
- 闭环控制：传感器反馈 -> 控制器计算 -> 修正输出
- 底盘功能实现：前进、后退、横移、转向
- 机构功能实现：升降台、夹爪、翻转、动作组
- 系统集成测试：把各模块拼起来后继续调参

## 6. 硬件层在做什么

- 设计机械结构
- 连接电机和通信线
- 做好供电和信号保护
- 处理线束和接口，避免比赛中被碰断
- 配置芯片和外设，让软件能真正跑起来

## 7. 在本工程里的对应位置

- `app/app_config.h`：全局参数、开关、标定值
- `app/protocol.h/.c`：上位机通信协议
- `app/hwt101.cpp`：陀螺仪航向和定角转向
- `app/distance_control.cpp`：光流距离闭环
- `app/action_group.cpp`：动作组状态机
- `sbus/sbus_control.cpp`：遥控器输入映射
- `wheel_chassis/*.cpp`：电机、PID、CAN、UART 相关驱动

## 8. 新队员建议先看什么

1. 先看 `app/app_config.h`，搞清楚有哪些功能开关和参数
2. 再看 `app/protocol.h/.c`，理解上位机怎么发命令
3. 接着看 `app/action_group.cpp`，理解动作流程
4. 再看 `app/hwt101.cpp` 和 `app/distance_control.cpp`
5. 最后看 `wheel_chassis/` 里的底层驱动

## 9. 一句话总结

- 电控 = 机械目标 + MCU 控制 + 通信协议 + 传感器反馈 + 硬件保护
